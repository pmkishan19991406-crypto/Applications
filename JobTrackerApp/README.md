# Job Application Tracker

A full-stack web application to manage and track job applications, interviews, and offers.  
Built with Spring Boot (REST API), MySQL (Database), and HTML/CSS/JavaScript (Frontend).

# Features

- CRUD Operations: Add, update, delete, and view job applications
- Search and Filter: Search by company name and filter by application status
- Dashboard: Real-time counts of total applications, applied, interviews, and offers
- Validation: Backend validation for required fields and salary constraints
- Exception Handling: Structured JSON error responses
- Timestamps: Auto-tracked creation and update times for each application

# Tech Stack

- Backend: Spring Boot, Spring Data JPA, Hibernate, REST API
- Frontend: HTML, CSS,  JavaScript (Fetch API)
- Database: MySQL
- Validation: Jakarta Validation
- Error Handling: RestControllerAdvice, custom exceptions
- Build Tool: Maven
